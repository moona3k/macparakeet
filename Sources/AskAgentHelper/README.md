# Ask agent helper

This private helper runs the published `@earendil-works/pi-agent-core` 0.87.1 loop. It is not the Pi coding-agent CLI. The direct Pi dependencies are MIT licensed and locked, including npm integrity hashes, in `package-lock.json`. The build copies a notice manifest and license files for the nine packages included in the generated bundle under `AskAgentHelper/Legal/`; the pinned Pi monorepo MIT license is kept in `legal/Pi-MIT-LICENSE`. `scripts/build_ask_helper.sh` uses `npm ci` and esbuild at build time; the app never installs packages at launch.

The app launches one helper per Ask run over private JSONL pipes. Every frame carries protocol version 1 and the run, scope, and request IDs. Pi can request only `list_sources`, `search`, `read`, and `get_summary`; Swift validates and executes those tools against the run's fixed source scope. A configured MacParakeet model runs in Swift through the injected Pi stream function. The helper receives no provider credentials and exposes no shell, filesystem, web, plugin, or arbitrary code tool to the model.

To verify an installed helper, set `MACPARAKEET_ASK_TEST_HELPER` to its `ask-helper.cjs` path when running `node --test test/*.test.js`. The tests launch that helper and inspect its adjacent `Legal/dependencies.json`, so CI verifies the packaged notices rather than relying on development build leftovers.

Run `npm test` for the real Pi loop tests. `ASK_TEST_NODE=/path/to/node npm test` checks a specific bundled Node binary. Runtime limits are 12 turns, 180 seconds, 32,000 characters per model request, 384,000 characters across requests, 32 KiB per tool result, 128 KiB total tool evidence, 80,000 answer characters, and 64 KiB per JSONL frame. The Swift host enforces its own frame and answer limits and terminates the process on cancellation. Character limits apply even when a provider does not report token usage. Pi requires a numeric internal usage field for synthetic bridge messages; its zero placeholder is never reported as actual provider usage or cost.
