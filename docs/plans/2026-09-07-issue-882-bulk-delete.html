Bulk deletion for Fix Words

One extra action in the everyday view.

Current

Recreated from current main. One word at a time.

Each word has an enable switch and its own delete action. Clearing a large import means repeating the same confirmation for every word.

Proposed

Try Select…, choose some words, then Delete….

Select… opens selection mode. Checkboxes replace the switches; a single delete action handles the selection. Select all also lets you clear the entire list.
