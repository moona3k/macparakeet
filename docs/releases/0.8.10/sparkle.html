New in 0.8.10

Meetings recover more reliably, transcripts are easier to correct, and long meeting cleanup uses less memory.

  • Set an exact speaker count before transcribing a file or link. Short replies such as “Yeah” stay with the speaker who said them. Unclaimed words are labelled Unattributed and left out of the count.
  • Find and replace words in a timed transcript. Each replacement undoes in one step.
  • A meeting microphone that fails to start is retried, and a missing microphone or system-audio side is called out.
  • Long meetings use less memory during the call and during echo cleanup. If live preview falls behind, some live words may skip. The saved recording is kept.
  • Optional second dictation shortcut for another keyboard. A shortcut such as ⌘D no longer also matches ⇧⌘D. Optional recording links stay off until you enable them in Capture settings; once on, other apps and websites can use them.
  • New libraries include meeting notes in Summary. Existing libraries keep their setting. Claude lists include the current models, and routine Keychain checks no longer ask for a password.
  • AI cleanup of a long transcript finishes instead of stopping at 30 seconds. A long recording is cleaned in sections.

Also included from 0.8.9

  • Turning AI off keeps saved API keys. Remove an unused key explicitly in AI Setup.
  • Use Apple Intelligence for Dictation & cleanup with Default AI set to None. Summaries, chat, and Transforms require another provider.
  • See each task's provider or Off. Prompt settings follow the provider assigned to that task.

Previously selected Apple Intelligence? Check Settings → AI Setup. An old Apple default is cleared; an old Apple analysis override falls back to Default AI. Saved keys remain.

Requires Apple Silicon and macOS 14.2+. Apple Intelligence requires macOS 26+ and enabled system models.
