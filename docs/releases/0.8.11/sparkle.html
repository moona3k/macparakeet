MacParakeet 0.8.11

Meeting recovery, dictation controls, and playback improvements.

  • Start another meeting while the previous recording finishes processing. Retry failed finalization from the saved meeting's detail view.
  • Opt-in Beta reminders offer to record supported meetings. Recording starts only when you choose Record.
  • Choose separate dictation start and stop sounds, adjust volume, or import your own. Includes original Bloom and Gong cues.
  • Optional links can start and stop dictation. Link control is off until enabled in Settings. Once enabled, other apps and websites can send these links.
  • More reliable paste/shortcut interaction and interrupted streaming insertion.
  • YouTube playback supports separate video and audio streams, with preparation progress. If a saved audio file is available, return to it by cancelling preparation or choosing Hide Video after a failed load.
  • File transcription reports temporary-storage failures during audio-track discovery.
  • Improved echo reduction in saved meeting transcripts when system audio and microphone timing are slightly offset. Incomplete knowledge cards get one corrective retry.
  • Automatic meeting titles recover from transient provider failures, retain valid topic years, and preserve adopted calendar names.
  • Compact Settings layouts and vocabulary fixes, including standalone C++, C#, and .NET.
  • Bundled CLI 5.2.0 returns saved corrections in history JSON and adds the activity_detection meeting trigger value.

Upgrading from an older version also brings transcript find and replace, speaker-count selection before transcription, a second dictation shortcut, meeting microphone recovery, and lower memory use during long meetings.

Apple Intelligence is available for Dictation & cleanup. Summaries, chat, and Transforms require another provider. Previously selected Apple Intelligence? Check Settings → AI Setup: an old Apple default is cleared, and an old Apple analysis override falls back to Default AI. Saved API keys remain.

Requires Apple Silicon and macOS 14.2 or later. Apple Intelligence requires macOS 26 or later and enabled system models.
