MacParakeet 0.8.8

Retry failed dictations, edit transcripts and saved AI results, and browse your Library faster.

Dictation

  • Retry failed recognition from History when Save dictation history is enabled.
  • More reliable Fn shortcuts and rapid restarts, with fixes for cancelled takes interfering with new recordings. Stop no longer waits on stalled live recognition.
  • Optional capture sounds, top or bottom pill placement, and a choice to let Escape pass through. Clean-mode dictation understands spoken “question mark” and “exclamation mark.”
  • An optional AI-polish shortcut for individual dictations. Requires AI Formatter to be enabled with a configured provider.

Library and editing

  • Edit transcript passages and saved AI results. Switching result tabs preserves your draft, and saving protects against overwriting newer edits.
  • Regenerate in the existing result tab; cancelling restores the saved result.
  • Faster Library loading and scrolling, more responsive long transcripts, and more room for Notes. Manage Prompts from the Library toolbar.
  • Cancellable folder imports and safer recording recovery.

AI and speech models

  • Choose separate AI models for cleanup and analysis, and choose from more languages for AI results. Run saved Transforms from the menu bar.
  • Use on-device Apple Intelligence on eligible Macs with macOS 26+. Best suited to short rewrites and cleanup.
  • Automatic speaker detection now uses Nemotron, with up to eight speakers per source. An additional model download and setup may be needed before offline use. Explicit speaker counts continue to use Community-1.
  • Try the optional Orukeet speech-recognition preview with a separate model download. Parakeet v3 remains the default; Orukeet does not support live dictation preview or recognition-time custom vocabulary. @Nathan-Roll1 contributed the MacParakeet integration for Oruk’s model.
  • Four-step onboarding with dictation practice and bundled CLI 4.9.0.

Requires Apple Silicon and macOS 14.2 or later.
