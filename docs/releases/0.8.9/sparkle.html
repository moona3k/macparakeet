Fixed in 0.8.9

A small follow-up to 0.8.8 for clearer AI setup and saved-key handling.

  • Turning AI off keeps saved API keys. Remove an unused key explicitly in AI Setup.
  • Use Apple Intelligence for Dictation & cleanup with Default AI set to None. Summaries, chat, and Transforms require another provider because Apple's model has a small context window.
  • See each task's provider or Off. Prompt settings follow the provider assigned to that task.

Previously selected Apple Intelligence? Check Settings → AI Setup after updating. An old Apple default is cleared; an old Apple analysis override falls back to Default AI. Saved keys remain. Choose Apple Intelligence under Dictation & cleanup to use it there.

Also included from 0.8.8

  • Retry failed dictations from History, with more reliable Fn shortcuts and rapid restarts.
  • Edit transcripts and saved AI results, regenerate in place, and browse a faster Library.
  • Choose separate AI models for cleanup and analysis, and choose from more output languages.
  • Try the optional Orukeet speech-model preview and Nemotron automatic speaker detection. Additional model downloads may be needed.

Requires Apple Silicon and macOS 14.2+. Apple Intelligence requires macOS 26+ and enabled system models.
