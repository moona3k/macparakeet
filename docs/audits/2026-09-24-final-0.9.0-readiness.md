## Verdict

**Source corrections have focused verification; stable publication remains on
hold.**
The prior 0.9.0 DMG was signed and notarized from `8038e35a` for physical QA,
but the corrections in this review supersede that candidate. A fresh exact-head
build, CI, signing, notarization, and physical QA are separate gates. `main` is
development; the published DMG and appcast remain 0.8.7 as of this review.

0.9.0 is the appropriate next version under the [distribution policy](../distribution.md#version-bumping):
the delta adds onboarding, editing and AI routing capabilities. A 0.8.8 patch
would describe the size of the release less accurately.

## Final source review

The pass checked dictation capture ownership and restart, prompt-result
persistence, CLI automation contracts, experimental Voice Control authority and
privacy, release feature gates, packaging, and changed docs/specs/ADRs.
Independent correctness, API-contract, security, documentation, and simplicity
passes informed the fixes below. File size alone did not justify a late view
model or coordinator refactor.

| Finding | Correction |
| --- | --- |
| A direct service restart could start a new capture while a normal stop was still finalizing the old recorder, or before the old live preview was retired. | Serialize normal capture stop through its health and device snapshots and retire old live/preview sessions with the existing start permit. Reject a provisional replacement stop before waiting on that permit; release it before recorded-file transcription so intended overlap remains. |
| Adding required `PromptResultRepositoryProtocol.updateContent` broke source compatibility for older conformers. | Supply a default that refuses unsafe edits with a typed error. The GRDB implementation retains its conditional transaction. |
| `voice-control replay --json` emitted plain-text errors for post-parse failures. | Route failures through the shared JSON envelope; keep the replay report's experimental field-shape exception explicit. |
| `spec --json` omitted vocabulary `replace-all`, and malformed/empty vocabulary imports were misclassified as runtime failures. | Advertise reset semantics and map rejected input to the documented error types and exit 2. Keep stale-preview conflict and I/O failure distinct. |
| Voice Control's selection snapshot closure captured a mutable weak reference in a concurrent `MainActor.run` closure. | Promote the weak reference before the actor hop. |
| ADR/spec/changelog entries described shipped timed corrections as development-only, implemented gated features as plans, or attributed post-tag CLI additions to older releases. | Align the release table, ADRs, architecture, CLI history, and Voice Control contract with implementation and feature flags. |
| Distribution instructions accepted remote DMG size alone as artifact identity. | Require SHA-256 equality for the exact appcast enclosure URL before publication. |

Voice Control, voice profiles, and encrypted share links remain disabled in
release builds. The security pass found no confirmed blocker in enabled paths.
Before enabling Voice Control, qualify Accessibility field-value handling and
network behavior on real native apps and browsers under its explicit consent
model; source inspection cannot establish that physical privacy result.
